# FP&A Standard Operating Procedures

FP&A 部門の標準業務手順書です。

## 全体像

```
FP&A
├─ 1. 戦略と整合した計画策定（Planning / Forecasting）
│  ├─ 1.1 中長期計画の策定
│  │  ├─ 事業シナリオの設計（成長ドライバ、前提条件、制約）
│  │  └─ 目標KPI・資本配分方針の定義
│  ├─ 1.2 年度予算の編成
│  │  ├─ 予算の構築（売上/粗利/OPEX/HC/CAPEX）
│  │  ├─ 配賦ルール・費目体系の設計
│  │  └─ 予算の合意形成（差戻し、例外処理、最終承認）
│  ├─ 1.3 ローリング予測の更新
│  │  ├─ 定期予測の更新（月次・四半期の着地見込み）
│  │  └─ リスク・機会の見える化（レンジ管理、確度区分）
│  └─ 1.4 シナリオ・感度の分析
│     ├─ 複数シナリオの策定（ベース・強気・弱気）
│     └─ 感度テストの実施（変数別インパクト定量化）
│
├─ 2. 業績の測定と説明（Measure & Explain）
│  ├─ 2.1 管理会計の締め支援
│  │  ├─ 実績データの取得と検証
│  │  │  ├─ 制度会計の締め完了確認とデータ取得
│  │  │  ├─ データの整合性検証（前月比連続性、異常値スクリーニング）
│  │  │  └─ 比較可能性の確保（科目体系・配賦ロジック変更時の影響記録）
│  │  ├─ 会計から管理へのブリッジ
│  │  │  ├─ 調整仕訳の作成（再分類、非経常項目の除外・調整）
│  │  │  ├─ 配賦計算の実行（間接費の部門別配賦、共通費の按分）
│  │  │  └─ 制度会計との差異照合（ブリッジテーブルによる一致確認）
│  │  └─ 管理会計実績の確定
│  │     ├─ 部門別PLの確定（事業部門・コストセンター別）
│  │     ├─ 管理指標の集計（管理会計ベースKPI、非財務指標の統合）
│  │     └─ 実績確定の承認と後続プロセスへの引き渡し
│  ├─ 2.2 予実差異の把握
│  │  ├─ 差異の算出とスクリーニング
│  │  │  ├─ 比較軸の選定と差異算出（BvA、FvA、前年同期比）
│  │  │  └─ 重要性の判定と深掘り対象の絞り込み（閾値判定、定性的フラグ）
│  │  ├─ 差異の要因分解
│  │  │  ├─ 数量・価格・ミックスの分解（PVM構造: 販売単価×数量×構成比の効果分離）
│  │  │  ├─ コスト構造の分解（固変分解・レート×効率分解: コストビヘイビアに基づく要因分離）
│  │  │  ├─ 為替影響の分離（実質業績と通貨換算効果の区分: 恒常為替レートベースの分析）
│  │  │  ├─ セグメント軸による分解（事業部門・製品・顧客・地域・チャネル等での差異配分）
│  │  │  └─ 複合要因の識別と分離（交互作用効果の処理、相殺差異の検出、分解順序の決定）
│  │  └─ ドライバの特定と影響度の評価
│  │     ├─ ドライバの分類（実行要因、外部要因、計画要因）
│  │     ├─ 性質の判別（一過性/構造的、コントロール可否）
│  │     └─ 通期着地への影響評価（ランレート換算、相殺差異・連鎖影響の識別）
│  ├─ 2.3 KPIの運用・モニタリング
│  │  ├─ KPIの定義と目標設定

│  │  │  ├─ 目標値・閾値の設定（ターゲット、アラート基準、ベンチマーク）

│  │  ├─ 定点観測と異常検知
│  │  │  ├─ ダッシュボードの運用（定期更新、信号灯表示、トレンド可視化）

│     ├─ レポートコンテンツの構成
│     │  ├─ 差異サマリーの統合（2.2の結果をウォーターフォール・コメンタリーに変換）
│     │  ├─ 業績ナラティブの作成（事実・解釈・提言の3層構造）
│     │  └─ フォワードルッキング情報の追加（着地見込み、リスク・機会、次期アクション）

│     │  ├─ 数値の整合性チェック（レポート間の一致、データソースへの遡及確認）
│     │  └─ 見せ方の標準化（チャート種類、配色、レイアウトの統一）
│     └─ レポートの配信と経営レビュー運営
│        ├─ 経営レポートの配信管理（経営会議・取締役会への報告サイクル）
│        ├─ 事業部パフォーマンスパッケージの配信（部門別PL・KPI・BvAコメンタリーの月次配信）
│        ├─ IR・開示部門への分析情報の提供（ガイダンス根拠、業績説明資料の素材、Q&A支援）
│        ├─ 経営レビュー会議の運営支援（アジェンダ設計、論点整理、アクションアイテム追跡）
│        └─ フィードバックの収集と改善（受け手の要望反映、レポート構成の継続的改善）
│
└─ 3. 打ち手の評価と提言（Evaluate & Recommend）
   ├─ 3.1 投資・資本配分の評価
   │  ├─ 投資案件の評価（NPV/IRR、回収期間、リスク調整）
   │  └─ ゲート管理の運営（継続/中止判断、条件変更）
   ├─ 3.2 収益施策の試算・支援
   │  ├─ 価格・値引き・条件変更のインパクト試算
   │  └─ 例外判断の支援（ルール整備、前例参照、承認プロセス）
   ├─ 3.3 コスト最適化・資源配分の分析
   │  ├─ OPEX最適化の分析（削減、再配分、ベンダー評価）
   │  └─ 人員計画の策定（HC枠管理、採用凍結/例外、配置最適化）
   └─ 3.4 キャッシュ・運転資本の管理
      ├─ 資金繰り予測の作成（入金/出金、支払条件管理）
      └─ ストレス時の優先順位策定（守る支出・止める支出）
```

### プロセスフローの補足

- 2.1→2.2→2.4 は月次締めサイクルの主要フロー（直列）
- 2.3（KPIモニタリング）は月次締めとは独立に稼働する並行プロセス。ダッシュボードの更新やアラート対応は日次/週次で実行され、月次締めの完了を待たない
- 2.4 の一部（フラッシュレポート）も月次締め完了前に発行される速報であり、2.2 の完了を前提としない
- フィードバック収集・KPI改廃・用語統一・可視化標準化は月次サイクルとは独立した改善活動であり、四半期〜年次で実施する

#### 隣接業務のインターフェース（SOPスコープ外）

- **アドホック分析依頼への対応**: 経営層からの突発的な分析依頼のトリアージ・優先順位付け。月次定例業務と同等以上の工数が発生することがあり、リソース管理上の重要論点
- **データガバナンス**: マスターデータの品質管理、データソースの整合性維持。2.1（データ取得・検証）の前提条件として重要
- **レポーティング自動化**: 定型レポートの自動生成・配信の仕組み構築。2.4 の効率化に直結するが、IT部門との協業領域
