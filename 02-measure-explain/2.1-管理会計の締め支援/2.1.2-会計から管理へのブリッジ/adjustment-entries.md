# 調整仕訳の作成

## 目的

- **誰のために**: FP&Aマネージャー、CFO、事業部門長
- **何を解決するか**: 制度会計の実績データは開示目的で組み立てられており、経営判断に必要な「事業の実態」を映さない。科目の粒度が管理会計と異なる、非経常的な損益が混在する、期間帰属が経済実態とずれている、といった差異を放置すると、予実比較や事業部門評価が歪み、誤った意思決定につながる
- **届ける価値**: 制度会計データを管理会計ベースに変換する調整仕訳を体系的に作成・管理することで、事業の経常的な収益力を正しく映す管理会計数値の基盤を提供する

## スコープ

- **対象**: 制度会計の月次実績データを管理会計実績に変換するための調整仕訳の作成プロセス。再分類（科目の読み替え）、非経常項目の除外・調整、期間帰属の調整を含む
- **前提**: 制度会計の月次締めが完了し、実績データの取得と検証が済んでいることが入力条件
- **後続**: 調整仕訳の適用後、配賦計算の実行に引き渡す。最終的に制度会計との差異照合で整合性を確認する
- **対象部門**: FP&A部門（実行主体）、経理部門（制度会計データ提供・調整内容の協議先）、事業部門（非経常項目の事実確認先）

## 責任者

| 役割 | 担当 |
|------|------|
| 調整仕訳の起票・実行 | FP&Aアナリスト |
| 調整ルールの設計・承認 | FP&Aマネージャー |
| 制度会計データの提供・調整根拠の確認 | 経理部門 |
| 非経常項目に関する事実確認 | 事業部門の予算責任者 |

## 手順

**用語の定義**:
- **再分類**: 制度会計の勘定科目を管理会計の費目体系に読み替えること。制度会計上の金額を変えずに、管理会計上の表示区分を変更する
- **非経常項目**: 通常の事業活動から反復的に発生するものではない損益項目。管理会計上、経常的な業績評価から除外または別掲する対象
- **ブリッジ仕訳**: 制度会計と管理会計の差異を説明可能な形で記録する調整仕訳。制度会計側の数値を増減させるのではなく、管理会計側の数値を構築するための仕訳

**プロセスの構造**

| フェーズ | ステップ | 実行条件 |
|---------|---------|---------|
| 前提整備 | 1. 科目マッピングテーブルの整備と維持 | 初回構築時または科目体系変更時。月次処理では参照のみ |
| 調整実行 | 2. 科目の再分類 | 毎月次。制度会計データ取得後に実施 |
| 調整実行 | 3. 非経常項目の識別と除外・調整 | 毎月次。ステップ2と順序不問だが、ステップ2完了後に実施する方が効率的 |
| 調整実行 | 4. 期間帰属の調整 | 制度会計と管理会計で期間認識が異なる項目がある場合 |
| 結果統合 | 5. 調整仕訳の記録と検証 | ステップ2-4完了後 |

### 1. 科目マッピングテーブルの整備と維持

**実行条件**: 初回構築時、年度予算編成時の費目体系見直し時、または制度会計側の科目体系変更時。月次の調整仕訳作成では既存のマッピングテーブルを参照する。

制度会計と管理会計では科目体系が異なるのが通常である。このマッピングテーブルが調整仕訳の基盤となる。

1. **制度会計科目と管理会計費目の対応関係を定義する**
   - 1対1マッピング: 制度会計の1科目が管理会計の1費目に対応（例: 「旅費交通費」→「出張旅費」）
   - 1対多マッピング: 制度会計の1科目を管理会計では複数費目に分割（例: 「人件費」→「基本給」「残業代」「福利厚生費」）
   - 多対1マッピング: 制度会計の複数科目を管理会計では1費目に集約（例: 「消耗品費」「事務用品費」「雑費」→「一般管理費・その他」）
   - 分割が必要な1対多マッピングには、分割基準（金額按分、件数按分、固定比率等）を併せて定義する

2. **マッピングテーブルに含めるべき属性**
   - 制度会計科目コード・科目名
   - 管理会計費目コード・費目名
   - マッピング種別（1対1 / 1対多 / 多対1）
   - 分割基準（1対多の場合）
   - P&L上の表示区分（売上原価 / 販管費 / 営業外等）
   - コストビヘイビア（固定 / 変動 / 準変動）との紐づけ

3. **マッピングテーブルの維持ルール**
   - 新規科目が追加された場合は、翌月の調整仕訳作成前にマッピングを確定する
   - 科目の統廃合があった場合は、前期比較の継続性を確保するため、旧科目との対応関係を履歴として残す
   - 年度予算編成時にマッピング全体を見直し、管理上不要な細分化や過度な集約がないか確認する

> **よくある落とし穴**: マッピングテーブルを一度作ったまま放置し、制度会計側の科目追加・変更を反映しないケース。未マッピング科目の金額が「その他」に流れ込み、管理会計の精度が徐々に劣化する。毎月の調整仕訳作成時に、未マッピング科目の有無を必ず確認する。

> **業種別の注意点**:
> - **製造業**: 製造原価報告書の科目体系と管理会計の費目体系の乖離が大きい。特に製造間接費の配賦前・配賦後の扱いに注意
> - **SaaS/テクノロジー**: 制度会計では「売上原価」に含まれるホスティング費用・カスタマーサクセス人件費を、管理会計ではユニットエコノミクス分析のために異なる区分に再配置する場合がある
> - **小売・流通**: 店舗ごとの損益管理のために、制度会計の本社一括計上科目を店舗別に再配分する再分類が発生する

---

### 2. 科目の再分類

**実行条件**: 毎月次。制度会計の実績データ取得後に実施する。

マッピングテーブルに従い、制度会計の科目を管理会計の費目体系に読み替える。金額の増減ではなく、表示区分の変更である。

1. **1対1マッピングの適用**
   - マッピングテーブルに基づき、制度会計科目の金額を管理会計費目に転記する
   - 金額の変更は行わない。制度会計上の金額がそのまま管理会計の対応費目に入る

2. **1対多マッピングの分割**
   - 分割基準に従い、制度会計の1科目の金額を管理会計の複数費目に配分する
   - 分割基準が「実績データに基づく比率」の場合（例: 人件費を職種別に分割）、当月の実績データ（人事データ等）を取得して比率を更新する
   - 分割基準が「固定比率」の場合、四半期ごとに比率の妥当性を検証する

3. **多対1マッピングの集約**
   - 制度会計の複数科目を管理会計の1費目に合算する
   - 集約前の科目別内訳はドリルダウン可能な形で保持する（分析時に細分化が必要になる場合があるため）

4. **未マッピング科目の処理**
   - 制度会計データにマッピングテーブルに存在しない科目が含まれていないか確認する
   - 未マッピング科目が存在する場合、金額の大小にかかわらず原因を特定する（新規科目の追加、科目コードの誤り、臨時科目の使用等）
   - 金額が軽微（総コストの0.1%未満が目安）な場合は、一時的に「未分類」として処理し、翌月までにマッピングを確定する
   - 金額が重要な場合は、経理部門に確認の上、当月中にマッピングを確定する

> **判断の分岐点**: 管理会計の費目体系をどこまで細かくするかは、分析の必要性と運用コストのバランスで決める。費目数が多いほど分析の粒度は上がるが、再分類の手間と分割基準の維持コストが増える。管理上の意思決定に実際に使われる粒度を基準に設計する。

### 3. 非経常項目の識別と除外・調整

**実行条件**: 毎月次。再分類の完了後に実施するのが効率的だが、並行して実施することも可能。

管理会計の目的は経常的な事業の収益力を正しく把握することにある。非経常項目を混在させたまま予実比較を行うと、業績評価が歪む。

1. **非経常項目の識別基準を定義する**
   - 以下のいずれかに該当する項目を非経常項目として扱う:
     - 頻度: 過去3年間に同種の取引が発生していない
     - 金額: 当該科目の月次平均額の3倍超（閾値は自社で定義する）
     - 性質: 事業運営の通常サイクル外（訴訟関連、災害損失、事業再編費用、減損損失、固定資産売却損益等）
   - グレーゾーンの判断基準: 「翌年度以降の予算に同種の費目を計上するか」で判断する。計上しないものは非経常として扱う

2. **非経常項目をリストアップする**
   - 経理部門から提供される特殊仕訳リスト・注記事項を入手する
   - 前月比で異常値が検出された科目（実績データの取得と検証の結果）を非経常候補として精査する
   - 事業部門からの報告（訴訟決着、資産売却、組織再編等）を収集する

3. **除外と調整の処理方法を決定する**
   - **全額除外**: 管理会計P&Lから全額を除外し、「非経常項目」として別掲する（例: 訴訟和解金、災害損失）
   - **金額調整**: 一部を経常、一部を非経常として分離する（例: リストラ費用のうち、退職加算金は非経常だが、後任採用費は経常）
   - **期間調整**: 制度会計上は一時に計上されるが、管理会計上は複数月に按分する方が実態を反映する場合（例: 年払い保険料の月次按分。ただしこれは通常ステップ4の期間帰属で処理する）
   - 処理方法ごとに調整仕訳を起票する

4. **非経常項目の一覧を維持する**
   - 月次で「非経常項目一覧」を更新する。項目ごとに: 発生月、金額、分類根拠、処理方法（除外/調整）、P&Lへの影響額を記録する
   - 経営報告では、経常ベースの管理会計P&Lに加え、非経常項目の一覧を別掲する。非経常項目を「なかったこと」にするのではなく、分離して可視化することが目的である

> **よくある落とし穴**: 非経常項目の定義が属人的になり、月ごと・担当者ごとに判断がぶれるケース。典型例は「大型の研修費用」「システム移行費用」「大口顧客の契約解除に伴う返金」など、経常と非経常の境界にある項目。判断の基準と過去の判断事例をリストとして蓄積し、一貫性を担保する。

> **判断の分岐点**: 非経常項目を除外しすぎると「都合の悪い数字を消している」と経営層の信頼を損なう。逆に除外が不十分だと分析のノイズが増える。原則は「予算に含まれていない性質の項目」を除外対象とし、金額が大きい項目は必ずFP&Aマネージャーの承認を得る。

> **業種別の注意点**:
> - **製造業**: 棚卸評価損・陳腐化損失の扱い。定期的に発生する少額の評価損は経常、大規模な一括償却は非経常と区分する
> - **SaaS/テクノロジー**: ストックオプション費用の扱い。制度会計上は人件費に含まれるが、管理会計上は除外して現金ベースの収益力を見る企業が多い。ただしIFRS/US-GAAP上の扱いと乖離が大きくなるため、ブリッジでの説明が重要
> - **金融業**: トレーディング損益やクレジットコスト（貸倒引当金繰入）の経常・非経常区分が業績評価に大きく影響する。ルールを明文化し、四半期ごとに経理部門と合意する

### 4. 期間帰属の調整

**実行条件**: 制度会計と管理会計で収益・費用の期間認識が異なる項目がある場合に実施する。

制度会計は会計基準に従った期間帰属であるが、管理会計では経営判断に適した期間帰属に調整する場合がある。

1. **期間帰属の調整が必要な項目を識別する**
   - 年払い・四半期払いの費用で、制度会計上は支払月に一括計上されるが、管理会計上は月次按分する方が実態を反映するもの（例: 年払い保険料、年間ライセンス料、賞与引当金の計上タイミング）
   - 売上の認識タイミングが制度会計と管理会計で異なるもの（例: 制度会計では検収基準だが、管理会計では出荷基準で認識する場合）
   - 制度会計で引当計上されているが、管理会計では実績ベースで認識するもの（またはその逆）

2. **月次按分の計算**
   - 年払い・四半期払い費用: 総額を対象月数で均等按分する。制度会計上の計上月と管理会計上の按分月の差額を調整仕訳で処理する
   - 賞与: 制度会計上の引当金繰入額と管理会計上の月次按分額の差異を調整する。管理会計上は、年間賞与見込額÷12ヶ月で月次均等化するのが一般的

3. **調整仕訳の起票**
   - 期間帰属の調整は、制度会計側の金額を「戻し」、管理会計上の正しい金額を「計上」する形で仕訳を作成する
   - 調整の前提（按分対象総額、按分月数、按分方法）を仕訳の摘要に記録する

> **よくある落とし穴**: 期間帰属の調整が蓄積すると、制度会計との差異が複雑化し、差異照合が困難になる。調整項目ごとに「制度会計累計」と「管理会計累計」を追跡し、年度末に一致することを確認する仕組みを設ける。

> **判断の分岐点**: 全ての期間帰属の差異を調整するのは過剰である。月次の管理会計P&Lの平準化に実質的に寄与する項目（月次変動が大きく、かつ金額が重要なもの）に限定する。年間を通じて累計額に差が出ない軽微な項目は、制度会計の期間帰属をそのまま使用する。

---

### 5. 調整仕訳の記録と検証

**実行条件**: ステップ2-4の調整が完了した後に実施する。

1. **調整仕訳台帳に記録する**
   - 全ての調整仕訳を「調整仕訳台帳」に記録する。仕訳ごとに以下の情報を含める:
     - 仕訳番号（一意の識別子）
     - 調整区分（再分類 / 非経常除外 / 非経常調整 / 期間帰属）
     - 借方科目・金額、貸方科目・金額
     - 摘要（調整の理由と根拠）
     - 起票者、承認者
   - 調整仕訳台帳は、制度会計との差異照合における「差異の内訳明細」として機能する

2. **貸借の一致を確認する**
   - 全ての調整仕訳の借方合計と貸方合計が一致することを確認する
   - 調整区分ごとの小計が、制度会計→管理会計のブリッジテーブルの各調整項目と一致することを確認する

3. **前月との継続性を確認する**
   - 毎月繰り返し発生する調整仕訳（定常的な再分類、月次按分等）が前月と同じパターンで計上されているか確認する
   - 前月にあった調整仕訳が当月に欠落していないか確認する（特に手動起票の仕訳）
   - 新規に追加された調整仕訳がある場合、その妥当性をFP&Aマネージャーが承認する

4. **管理会計P&Lの完成と引き渡し**
   - 制度会計実績 + 調整仕訳 = 管理会計実績（調整前）として、配賦計算の実行に引き渡す
   - 調整仕訳台帳を制度会計との差異照合の入力資料として引き渡す

> **よくある落とし穴**: 調整仕訳の摘要が「再分類」「調整」などの抽象的な記述のみで、後から調整の根拠が追えなくなるケース。摘要には「何を」「なぜ」「どの基準に基づいて」調整したかを具体的に記載する。担当者が交代しても追跡可能な粒度が基準である。
