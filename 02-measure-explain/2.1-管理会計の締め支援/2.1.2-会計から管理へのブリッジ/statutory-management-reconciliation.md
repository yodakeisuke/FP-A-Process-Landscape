# 制度会計との差異照合

## 目的

- **誰のために**: CFO、FP&Aマネージャー、経理部門長、内部監査部門
- **何を解決するか**: 管理会計の数値は調整仕訳・配賦を経て制度会計から乖離する。この乖離が「意図した調整」なのか「意図しないエラー」なのかを区別できなければ、管理会計数値の信頼性が担保されず、経営判断の基盤が揺らぐ。また、制度会計との差異を説明できない管理会計は、監査対応や外部開示との整合性確保においてもリスクとなる
- **届ける価値**: ブリッジテーブルを通じて制度会計と管理会計の差異を全額・全項目にわたり説明可能な状態にすることで、管理会計数値の信頼性を証明し、経営陣・監査人・ステークホルダーに対する説明責任を果たす

## スコープ

- **対象**: 管理会計の確定数値と制度会計の確定数値の照合プロセス。ブリッジテーブルの作成・更新、差異の原因特定、未解消差異の処理を含む
- **前提**: 調整仕訳の作成および配賦計算の実行が完了していることが入力条件。制度会計の月次実績が確定していること
- **後続**: 照合完了により管理会計実績の確定に進む。未解消差異がある場合は是正措置を講じた上で確定する
- **対象部門**: FP&A部門（実行主体）、経理部門（制度会計データの提供・差異原因の確認先）

## 責任者

| 役割 | 担当 |
|------|------|
| 照合の実行・差異分析 | FP&Aアナリスト |
| 照合結果の承認・未解消差異の判断 | FP&Aマネージャー |
| 制度会計データの提供・差異原因の確認 | 経理部門 |
| 照合プロセスの監査 | 内部監査部門（定期的） |

## 手順

**用語の定義**:
- **ブリッジテーブル**: 制度会計の数値から管理会計の数値に至るまでの調整項目を一覧化した表。「制度会計 ± 調整項目 = 管理会計」の構造を持ち、差異の全額を調整項目として説明する
- **照合差異**: ブリッジテーブル上で説明できない制度会計と管理会計の差額。意図した調整の漏れ、計算誤り、データの取り込みエラー等に起因する
- **許容差異**: 端数処理や為替レートの端数等により不可避的に生じる微少な差異。事前に定義した閾値以内であれば照合完了として扱う

**プロセスの構造**

| フェーズ | ステップ | 実行条件 |
|---------|---------|---------|
| 照合準備 | 1. ブリッジテーブルの構造設計と維持 | 初回構築時または構造変更時。月次処理では既存構造を使用 |
| 照合実行 | 2. P&L項目の照合 | 毎月次。調整仕訳・配賦計算完了後 |
| 照合実行 | 3. 差異の原因特定と解消 | 照合差異が検出された場合 |
| 結果確定 | 4. 照合結果の確定と引き渡し | ステップ2-3完了後 |

### 1. ブリッジテーブルの構造設計と維持

**実行条件**: 初回構築時、年度予算編成時の費目体系変更時、または調整ルール・配賦ルールの大幅変更時。月次の照合では既存の構造を使用する。

ブリッジテーブルは制度会計と管理会計の「翻訳表」であり、全ての差異を構造的に説明するための基盤である。

1. **ブリッジテーブルの基本構造を設計する**
   - 行: P&Lの科目（制度会計の科目体系を起点とする）
   - 列: 以下の構造で左から右に展開する

   | 列 | 内容 |
   |----|------|
   | A. 制度会計実績 | 経理部門が確定した制度会計ベースのP&L |
   | B. 科目再分類 | 勘定科目の管理会計費目への読み替え（金額の増減なし、表示区分の変更） |
   | C. 非経常項目除外 | 非経常項目の除外・調整額 |
   | D. 期間帰属調整 | 収益・費用の期間認識の調整額 |
   | E. 配賦調整 | 間接費の配賦・共通費の按分による増減 |
   | F. その他調整 | 上記に分類されないその他の調整額 |
   | G. 管理会計実績 | A + B + C + D + E + F = G |

   - 各列の合計（P&L全体の合計）において、B列（再分類）は合計ゼロになる（表示区分の変更のみで金額増減がないため）
   - E列（配賦調整）も合計ゼロになる（間接費の配賦先変更であり、全社合計では増減がないため）
   - C列・D列・F列は合計がゼロにならない場合がある（非経常項目の除外や期間帰属の変更は、管理会計P&Lの合計を制度会計P&Lの合計から乖離させる）

2. **粒度を決定する**
   - P&L全体の一致確認だけでは不十分。最低限、以下の粒度で照合する:
     - 損益区分別（売上高、売上原価、販管費、営業外損益）
     - 主要科目別（金額上位20科目程度）
   - 部門別の照合が必要な場合（配賦の正確性を検証する場合）、部門×科目のマトリクスで照合する

3. **ブリッジテーブルの維持ルール**
   - 調整区分（B-F列）の追加・変更があった場合は、ブリッジテーブルの列構造を更新する
   - 新たな調整類型が発生した場合は、既存の区分に含めるか新規列を追加するかをFP&Aマネージャーが判断する
   - 年度末に、年間を通じたブリッジテーブルの構造を振り返り、翌年度の改善点を特定する

> **判断の分岐点**: ブリッジテーブルの粒度は「差異を説明可能か」と「維持コスト」のバランスで決める。全科目×全部門×全調整区分のフルマトリクスは理想的だが、維持コストが高い。まずP&L主要項目レベルで構築し、照合差異が頻発する領域を特定してから、その領域のみ粒度を上げるのが実務的である。

---

### 2. P&L項目の照合

**実行条件**: 毎月次。調整仕訳の作成と配賦計算の実行が完了した後に実施する。

ブリッジテーブルに当月の数値を投入し、制度会計から管理会計への変換が正しく行われたかを確認する。

1. **制度会計実績をブリッジテーブルのA列に投入する**
   - 経理部門が確定した当月の制度会計P&Lの数値をA列に転記する
   - 転記元のデータソースと転記先の金額が一致することを確認する（手入力の場合は特に注意）

2. **調整仕訳の金額をB-F列に投入する**
   - 調整仕訳台帳の仕訳を、調整区分（再分類 / 非経常除外 / 期間帰属 / 配賦 / その他）に従ってB-F列に転記する
   - 各調整区分の合計が、調整仕訳台帳の区分別合計と一致することを確認する
   - 配賦計算の結果をE列に反映する。配賦元（マイナス）と配賦先（プラス）の合計がゼロになることを確認する

3. **管理会計実績（G列）を算出し、管理会計P&Lと照合する**
   - G列 = A + B + C + D + E + F として自動算出する
   - G列の値と、配賦後の管理会計P&L（部門別PL確定プロセスに引き渡す数値）が一致することを確認する
   - 照合の単位: まず損益区分別（売上高、売上原価、販管費、営業外）の合計で一致を確認し、次に主要科目別に確認する

4. **クロスチェックを実施する**
   - B列（再分類）の全科目合計がゼロであることを確認する
   - E列（配賦調整）の全科目合計がゼロであることを確認する
   - 管理会計P&Lの営業利益と制度会計P&Lの営業利益の差額が、C列 + D列 + F列の合計と一致することを確認する（全社合計レベル）

> **よくある落とし穴**: 照合を「合計金額の一致」だけで済ませ、科目レベルの照合を怠るケース。合計が一致していても、個別科目レベルでプラスマイナスが相殺されて見かけ上一致している場合がある。最低限、主要科目レベルでの照合を毎月実施する。

> **業種別の注意点**:
> - **製造業**: 製造原価報告書の科目体系と管理会計の費目体系の乖離が大きいため、ブリッジテーブルの再分類列が複雑になる。製造原価報告書→売上原価→管理会計費目の2段階ブリッジが必要な場合がある
> - **SaaS/テクノロジー**: ストックオプション費用やキャピタライズした開発費の扱いが制度会計と管理会計で大きく異なる企業が多い。これらの項目のブリッジは特に丁寧に管理する
> - **グローバル企業**: 現地法人の制度会計（現地GAAP）と連結管理会計（IFRS/US-GAAPベース）の間にGAAP差異が存在する。為替換算差異と合わせて、ブリッジの複雑性が増す

---

### 3. 差異の原因特定と解消

**実行条件**: ステップ2の照合で、許容差異を超える照合差異が検出された場合に実施する。

照合差異はゼロが理想だが、実務上は端数処理等により微少な差異が生じうる。許容差異を超える差異は原因を特定し、解消する。

1. **許容差異の基準を定義する**
   - 全社P&L合計レベル: ±1,000円以内（端数処理による差異のみ許容）
   - 損益区分別: ±10,000円以内（目安。自社の金額規模に応じて設定）
   - 科目別: ±10,000円以内または当該科目金額の0.1%以内のいずれか大きい方
   - 許容差異の基準は年度初に設定し、FP&Aマネージャーが承認する

2. **差異の原因を分類する**
   - 照合差異が検出された場合、以下のカテゴリで原因を切り分ける:

   | 原因カテゴリ | 具体例 | 解消方法 |
   |------------|--------|---------|
   | データ取り込みエラー | 制度会計データの転記ミス、抽出条件の誤り | データの再取得・再転記 |
   | 調整仕訳の漏れ | 新規発生した調整項目の未計上、定常仕訳の計上漏れ | 追加仕訳の起票 |
   | 調整仕訳の計算誤り | 按分比率の誤り、配賦基準データの誤り | 仕訳の修正 |
   | 配賦計算の誤り | 配賦レートの計算ミス、端数処理の不整合 | 配賦計算の再実行 |
   | タイミング差異 | 制度会計と管理会計でデータの締め日が異なる | 差異内容の記録と翌月の洗い替え |
   | マッピングの不備 | 科目マッピングテーブルの更新漏れ | マッピングテーブルの修正と再分類 |

3. **差異を解消する**
   - データエラー・計算誤りの場合: 元データの修正または仕訳の修正を行い、照合を再実行する
   - 調整仕訳の漏れの場合: 追加仕訳を起票し、調整仕訳台帳に記録した上で照合を再実行する
   - タイミング差異の場合: 差異の内容と金額を「タイミング差異明細」として記録し、翌月に洗い替わることを確認する。2ヶ月連続で同じタイミング差異が残る場合は、締めプロセスの見直しが必要

4. **未解消差異の処理**
   - 原因が特定できたが当月中に解消できない差異は、「未解消差異明細」に記録する
   - 未解消差異が許容差異の範囲内であれば、照合完了として扱い、翌月以降に解消を追跡する
   - 未解消差異が許容差異を超える場合、FP&Aマネージャーが以下を判断する:
     - 管理会計実績の確定を保留し、差異解消を優先するか
     - 未解消差異を注記付きで管理会計実績に含め、確定を進めるか
   - 未解消差異が3ヶ月連続で残存する場合は、根本原因の調査をエスカレーションする

> **よくある落とし穴**: 照合差異を「前月からの繰越差異」として毎月持ち越し、原因を究明しないまま蓄積するケース。差異が蓄積すると、個別の原因特定が困難になり、管理会計全体の信頼性が徐々に低下する。差異は発生月に原因を特定し、遅くとも翌月中に解消することを原則とする。

> **判断の分岐点**: 差異の原因特定に時間がかかり、管理会計の締め期限に間に合わない場合、「暫定確定→翌月修正」か「締め延長→確定版の精度確保」かの判断が必要。経営報告のスケジュールとの兼ね合いで判断するが、原則として金額が営業利益の1%未満の差異であれば暫定確定を許容し、それを超える場合は締め延長を検討する。

### 4. 照合結果の確定と引き渡し

**実行条件**: ステップ2-3が完了した後に実施する。

1. **照合完了の承認を得る**
   - 照合結果（ブリッジテーブル、差異明細、未解消差異一覧）をFP&Aマネージャーに提出し、承認を得る
   - 承認の判断基準:
     - 全ての調整項目がブリッジテーブル上で説明されていること
     - 未解消差異が許容範囲内であること
     - タイミング差異の洗い替え計画が明確であること

2. **ブリッジサマリーを作成する**
   - 経営報告用に、ブリッジテーブルの要約版を作成する。営業利益レベルで:
     - 制度会計の営業利益
     - (±) 非経常項目の除外・調整
     - (±) 期間帰属の調整
     - (±) その他調整
     - = 管理会計の営業利益
   - ウォーターフォールチャートで可視化すると、経営層への説明が容易になる

3. **後続プロセスへの引き渡し**
   - 管理会計実績の確定プロセスに、照合済みの管理会計P&Lとブリッジテーブルを引き渡す
   - 経営レポートの作成プロセスに、ブリッジサマリーを引き渡す
   - 予実差異の把握プロセスに、管理会計ベースの実績データを引き渡す

4. **照合プロセスの振り返りと改善**
   - 四半期ごとに照合プロセスを振り返り、以下を確認する:
     - 照合差異の発生頻度と主な原因パターン
     - 照合に要する時間の推移
     - マッピングテーブルや調整ルールの改善余地
   - 同じ原因の照合差異が繰り返し発生する場合、上流プロセス（調整仕訳、配賦計算）の改善を行う

> **よくある落とし穴**: 照合プロセスを「形式的なチェック」として位置づけ、ブリッジテーブルの維持を軽視するケース。ブリッジテーブルは管理会計の「信頼性の証明書」であり、監査対応・経営層への説明・担当者交代時の引き継ぎの全てにおいて基盤となる。作成して終わりではなく、毎月の更新と定期的な構造見直しを組み込む。
