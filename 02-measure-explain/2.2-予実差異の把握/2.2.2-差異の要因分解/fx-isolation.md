# 為替影響の分離

## 目的

- **誰のために**: CFO、事業部門長、IR担当、海外事業責任者
- **何を解決するか**: 為替レートの変動を含んだまま業績を評価すると、事業の実力（実質業績）と通貨変動による会計上の影響が混在し、事業部門の真のパフォーマンスが見えなくなる。「増収だが実質減収」「減益だが為替要因を除けば増益」といった判断ができない
- **届ける価値**: 為替影響を分離し、恒常為替レート（Constant Currency）ベースの実質業績を算出することで、事業パフォーマンスの正確な評価と、為替リスクの定量把握を可能にする

## スコープ

- **対象**: 予実差異の要因分解プロセスのうち、為替レート変動による影響の分離。売上・コスト双方に適用される
- **前提**: 比較軸の選定と差異算出、および重要性の判定と深掘り対象の絞り込みで重要性ありと判定された差異が入力となる。また、外貨建て取引や海外子会社を有する事業体が対象
- **後続**: 為替影響を分離した後の恒常為替レートベースの数値が、PVM分解やコスト構造分解の入力となる。為替影響の分離は他の分解に先行して実施する
- **対象部門**: FP&A部門（実行主体）、経理部門（為替レート情報・換算データの提供元）、財務部門（ヘッジ情報の提供元）、海外事業部門（現地業績のコンテキスト提供元）

## 責任者

| 役割 | 担当 |
|------|------|
| 為替影響の分離・分析 | FP&Aアナリスト |
| 恒常為替レート方針の設計・承認 | FP&Aマネージャー |
| 為替レートデータ・換算実績の提供 | 経理部門 |
| ヘッジ実績・方針情報の提供 | 財務部門（トレジャリー） |
| 現地通貨ベースの業績コンテキスト提供 | 海外事業部門責任者 |

## 手順

**用語の定義**:
- **恒常為替レート（Constant Currency Rate）**: 比較対象期間（予算策定時、前年同期等）の為替レートのこと。実績の外貨建て数値をこのレートで換算し直すことで、為替変動の影響を除いた比較を行う
- **取引為替影響（Transaction Effect）**: 外貨建て取引を自国通貨に換算する際に生じる為替影響。実際のキャッシュフローに影響する
- **換算為替影響（Translation Effect）**: 海外子会社の財務諸表を親会社の報告通貨に換算する際に生じる為替影響。連結手続上の影響であり、個社のキャッシュフローには直接影響しない

**プロセスの構造**

| フェーズ | ステップ | 実行条件 |
|---------|---------|---------|
| 前提整備 | 1. 恒常為替レートの定義と管理 | レート方針の新規策定時または年次見直し時。月次分析時は既存のレートを適用 |
| 分解実行 | 2. 取引為替影響の算出 | 外貨建て取引がある場合 |
| 分解実行 | 3. 換算為替影響の算出 | 海外子会社の連結がある場合。ステップ2と順序不問 |
| 結果統合 | 4. 為替影響の統合と実質業績の算出 | ステップ2-3のうち該当するものの完了後 |

### 1. 恒常為替レートの定義と管理

**実行条件**: 予算策定時（年次）に恒常為替レートを設定する。月次の差異分析では設定済みのレートを参照する。

為替影響の分離の精度と一貫性は、恒常為替レートの定義に依存する。レートの選択が期中に変わると、比較可能性が損なわれる。

1. **恒常為替レートの基準を選定する**
   - 予算レート: 予算策定時に設定した為替レート。BvA（予算対実績）分析の基準として最も一般的
   - 前年実績レート: 前年同期の平均為替レート。YoY（前年同期比）分析の基準として使用
   - 期首スポットレート: 期首時点のスポットレートを年間固定で使用。簡便だが期中の市場変動を反映しない
   - 分析目的に応じて使い分ける。通常、月次のBvAレポートでは予算レートを恒常為替レートとして使用する

2. **通貨別のレートテーブルを維持する**
   - 関連する全通貨ペアについて、恒常為替レートと実績レートの対照表を管理する
   - 実績レートは、月中平均レート（P/L項目）と期末レート（B/S項目）を区別する
   - レートテーブルの更新タイミング: 月次の実績為替レートは経理部門の締め処理と同期する

3. **為替レートの適用方針を統一する**
   - P/L項目: 月中平均レート（会計上のレート）を実績レートとする
   - B/S項目: 期末レート（会計上のレート）を実績レートとする
   - 予算レートとの比較: 通常、予算は単一の年間レートで策定される。月次分析では予算の年間レートと当月の実績レートの差異を計算する
   - ヘッジレートの扱い: ヘッジ取引でレートが確定している部分は、ヘッジ後の実効レートを使用する。ヘッジの効果を為替影響に含めるか、別枠で表示するかは方針として統一する

4. **財務部門（トレジャリー）との連携体制**
   - 為替影響の分離には、財務部門が管理するヘッジ情報が不可欠である
   - **月次の連携**: FP&Aアナリストは月次で財務部門から以下を入手する
     - 当月のヘッジ実績（通貨別のヘッジカバー率、ヘッジレート）
     - 翌月以降のヘッジポジション（通期着地への影響評価に使用）
     - ヘッジ方針の変更があった場合の通知
   - **入手のタイミング**: 経理部門の締め完了後、差異算出と並行して財務部門に依頼する。為替影響の分離はPVM分解やコスト構造分解の前工程であるため、この情報の入手が遅れると後続プロセス全体に影響する
   - 財務部門との連携は形式的なデータ受領にとどまらず、為替市場のトレンドに関する見解も確認する。「今後の為替見通しについて市場はどう見ているか」という情報は、通期着地への影響評価で活用できる

> **判断の分岐点**: ヘッジの効果を為替影響の分離に組み込む方法は2通りある。(A) ヘッジ後の実効レートを「実績レート」として使い、恒常為替レートとの差異を計算する方法。(B) ヘッジ前の市場レートで為替影響を算出し、ヘッジ損益を別行で表示する方法。(A)は事業部門の最終的な為替インパクトを示し、(B)はヘッジ部門の貢献を可視化する。経営の情報ニーズに応じて選択する。

> **業種別の注意点**:
> - **多国籍製造業**: 多数の通貨ペアが存在し、換算為替影響が大きい。通貨別・地域別の重要度に応じて精密分析と簡便分析を使い分ける（上位3-5通貨を精密分析、その他は一括処理）
> - **SaaS/テクノロジー**: USD建ての売上が中心でも、各国子会社の人件費（JPY、EUR、INR等）はコスト側の取引為替影響を受ける。売上は為替影響が小さくても、コスト側で影響が大きいケースがある
> - **輸入型ビジネス**: 仕入が外貨建て、売上が自国通貨建ての場合、為替変動がコストに直結する。為替影響は粗利率を通じて収益性に影響するため、売上とコストの為替エクスポージャーの非対称性に注意する

### 2. 取引為替影響の算出

**実行条件**: 外貨建て取引がある場合に実施する。

取引為替影響は、外貨建ての売上やコストを報告通貨に換算する際に、為替レートの変動によって生じる差異である。

1. **外貨建て取引の実績データを通貨別に取得する**
   - 売上: 通貨別・製品別（可能であれば取引別）の外貨建て売上高
   - コスト: 通貨別・科目別の外貨建てコスト
   - データソースは経理システムの仕訳データまたは管理会計システムの通貨別実績
   - **経理部門との連携**: 通貨別の実績データは、経理部門の協力なしには正確に取得できない。経理部門に対して「どの粒度で通貨別データが必要か」を事前に伝え、月次の締め処理の中でデータ出力を組み込んでもらう。毎月アドホックに依頼するのではなく、定例プロセスとして確立する

2. **恒常為替レートで換算し直す**
   - 恒常為替レートベースの金額 = 外貨建て実績金額 × 恒常為替レート
   - 実績為替レートベースの金額 = 外貨建て実績金額 × 実績為替レート（これは会計上の実績値）
   - 取引為替影響 = 実績為替レートベースの金額 − 恒常為替レートベースの金額

3. **取引為替影響をP/Lの科目別に集計する**
   - 売上の取引為替影響: 外貨建て売上に対する為替影響
   - 売上原価の取引為替影響: 外貨建て仕入・外注費等に対する為替影響
   - 販管費の取引為替影響: 海外出張費、海外拠点費用等に対する為替影響
   - 粗利への為替影響 = 売上の取引為替影響 − 売上原価の取引為替影響。売上とコストの通貨構成が異なる場合、粗利への影響は単純な合算にならない点に注意する。例えば、円安は外貨建て売上を円換算で増加させるが、同時に外貨建て仕入コストも増加させる。売上とコストの外貨建て比率が異なれば、粗利への純影響は売上側・コスト側の相殺後の金額となる

4. **ヘッジ効果を反映する**（ヘッジ取引がある場合）
   - ヘッジで確定したレートが適用される取引を識別する
   - ヘッジ対象取引の為替影響は、ヘッジレートと恒常為替レートの差異で再計算する
   - ヘッジカバー率（ヘッジ対象 ÷ 全外貨建て取引）を記録し、為替リスクの残存度合いを把握する
   - ヘッジ会計の適用状況を経理部門に確認する。ヘッジ会計が適用されている取引と適用されていない取引では、P/L上の為替影響の計上タイミングが異なるため、管理会計上の為替影響算出に影響がないか確認する

> **よくある落とし穴**:
> - **ネッティングの見落とし**: 同一通貨の売上とコストが両方ある場合、為替影響はネット（売上−コスト）に対して生じる。グロスベースで為替影響を算出すると、自然ヘッジ（売上と仕入が同一通貨）の効果が見えず、為替リスクを過大評価する
> - **タイミングの不一致**: 月中平均レートは経理部門が採用する平均レートの定義（日次平均、月初月末平均等）と一致させる。FP&Aが独自にレートを取得すると、制度会計の数値との照合で不一致が生じる
> - **為替差損益との混同**: 経理上の「為替差損益」（外貨建て債権債務の決済時や期末評価替え時に計上）と、管理会計上の「為替影響の分離」は異なる概念。前者は会計上の損益であり、後者は分析上の仮想的な影響額。両者を混同しない

### 3. 換算為替影響の算出

**実行条件**: 海外子会社の連結がある場合に実施する。ステップ2と順序不問で実施可能。

換算為替影響は、海外子会社の現地通貨建て財務諸表を親会社の報告通貨に換算する際に生じる差異である。子会社自体の業績は変わらないが、連結ベースの数値が変動する。

1. **海外子会社の現地通貨建て実績を取得する**
   - 子会社のP/Lを現地通貨ベースで取得する
   - 子会社ごとの機能通貨（functional currency）を確認する。機能通貨は必ずしも所在国の通貨とは限らない（例: シンガポール法人がUSDを機能通貨としている場合）

2. **恒常為替レートと実績為替レートの双方で換算する**
   - 恒常為替レートベース = 子会社現地通貨建て実績 × 恒常為替レート
   - 実績為替レートベース = 子会社現地通貨建て実績 × 実績為替レート（これは連結会計上の実績値）
   - 換算為替影響 = 実績為替レートベースの金額 − 恒常為替レートベースの金額

3. **子会社別・通貨別に換算為替影響を集計する**
   - 子会社の規模（連結売上に占めるシェア）と為替レートの変動幅の組み合わせで、影響の大きい子会社を特定する
   - 通貨別の集計: 同一通貨の子会社が複数ある場合（例: 欧州の複数のEUR建て子会社）は通貨単位で集約する

4. **換算為替影響とローカル業績の分離を確認する**
   - 子会社の業績差異（ローカル通貨ベース）と換算為替影響は完全に独立した情報
   - 「子会社Aは現地通貨ベースでは10%増収だが、通貨安により円建てでは3%減収」のように、ローカル業績と換算効果を明確に区分して報告する
   - 海外事業部門の業績評価は原則として恒常為替レートベース（ローカル通貨ベース）で行い、換算為替影響は全社のリスク管理として別途管理する

5. **海外事業責任者との認識合わせ**
   - 換算為替影響が大きい子会社については、現地の事業責任者と認識を合わせる
   - **確認すべきポイント**:
     - 現地通貨ベースの業績に対する事業責任者自身の評価
     - 現地の為替環境（インフレ率、金融政策、通貨の安定性等）に関する現場の肌感覚
     - 現地での為替リスク対応（現地での価格転嫁の可能性、現地調達へのシフト等）
   - この情報は、通期着地への影響評価で為替影響が構造的か一過性かを判断する際に活用する
   - **コミュニケーション上の注意**: 海外事業責任者にとって、本社報告通貨（円）での為替影響は自身の管理範囲外と認識される場合が多い。「為替の影響で円建ての業績が悪化している」と伝える際は、「現地通貨ベースの実力は認識している。本社報告上の影響を正確に把握するための確認である」というスタンスを明確にする

> **判断の分岐点**: 海外子会社が多数ある場合、全子会社の換算影響を精密に算出するか、上位子会社のみ精密分析するかの判断が必要。目安として、連結売上の5%以上を占める子会社、または為替レートが前期比で5%以上変動した通貨に関連する子会社を精密分析対象とし、それ以外は簡便法（通貨別の一括換算）を適用する。

> **よくある落とし穴**: 海外子会社の中に、現地通貨建てのP/Lが取引為替影響を既に含んでいるケースがある。例えば、欧州子会社（EUR建て）がUSD建ての売上を持つ場合、子会社P/L上のEUR建て売上には取引為替影響が反映済み。この場合、親会社での換算為替影響（EUR→JPY）と子会社レベルの取引為替影響（USD→EUR）が重層的に存在する。二重計上を防ぐため、取引為替影響と換算為替影響の境界を明確にする。

### 4. 為替影響の統合と実質業績の算出

**実行条件**: ステップ2-3のうち該当するステップが完了した後に実施する。

1. **為替影響の合計を算出する**
   - 総為替影響 = 取引為替影響 + 換算為替影響
   - P/Lの主要ラインごとに為替影響を表示する: 売上高、売上原価、粗利益、販管費、営業利益
   - 通貨別の為替影響内訳を付記する（主要通貨3-5通貨、その他は一括）

2. **恒常為替レートベースの実質業績を確定する**
   - 恒常為替レートベースの実績 = 報告通貨ベースの実績 − 総為替影響
   - あるいは: 外貨建て実績を恒常為替レートで換算した金額（ステップ2-3で算出済み）
   - 両方のアプローチで計算し、結果が一致することを検証する

3. **為替影響のブリッジを作成する**
   - ウォーターフォール形式: 基準売上 → 恒常為替レートベースの変動 → 為替影響 → 実績売上
   - このブリッジにより、実質的な事業成長と為替効果を視覚的に分離できる
   - 同様のブリッジを粗利益・営業利益についても作成する

4. **後続の分解への入力データを準備する**
   - PVM分解への入力: 恒常為替レートベースの製品別売上（為替影響を除去済み）
   - コスト構造分解への入力: 恒常為替レートベースの科目別コスト（為替影響を除去済み）
   - 分解の順序: FX分離 → PVM分解/コスト構造分解 → セグメント軸分解、の順序を守る。FX分離を先に行わないと、他の分解結果に為替影響が混入する

5. **為替影響の経営報告に向けた準備**
   - 為替影響は、IR部門や経営企画部門にとっても重要な情報である
   - **IR部門への情報提供**: 決算開示前に、IR部門に為替影響の定量情報（売上・利益への影響額、主要通貨別の内訳）を提供する。IR部門は投資家向け説明で「恒常為替ベースの成長率」を使用することが多いため、数値の一貫性を確保する
   - **経営会議での報告方法**: 為替影響は「事業の実力」とは独立した要因であることを明確にし、「報告通貨ベース」と「恒常為替ベース」の両方の業績を並べて報告する。為替の有利/不利によって事業部門の業績評価が歪まないよう、事業部門の実力評価は恒常為替ベースで行うことを原則とする
   - **財務部門へのフィードバック**: 為替影響の分析結果を財務部門にもフィードバックする。「どの通貨の影響が最も大きかったか」「ヘッジカバー率は十分だったか」の情報は、財務部門のヘッジ戦略の検証に活用される

6. **ドライバの分類・性質の判別・通期着地への影響評価への引き渡し情報**
   - 為替影響額（売上・コスト・利益への影響）
   - 影響の大きい通貨ペアとその変動幅
   - 一過性か構造的かの初期判断:

   | パターン | 初期判断 | 根拠 |
   |---------|---------|------|
   | 金融政策の変更に伴う通貨変動 | 構造的 | 政策サイクルに依存し短期では戻りにくい |
   | 地政学イベントによる急激な通貨変動 | 判断保留 | イベントの持続性に依存。継続監視 |
   | 新興国通貨の趨勢的な減価 | 構造的 | インフレ格差等の構造要因が背景 |
   | 季節的な為替変動パターン | 一過性 | 年間サイクルの中で平準化される |

   - ヘッジカバー率と残存エクスポージャーの規模
   - 通期への影響見込み（現在のフォワードレートに基づく年間影響額の概算）

> **業種別の注意点**:
> - **輸出型製造業**: 売上の為替感応度が高い。円安は増収要因、円高は減収要因として大きく影響。自然ヘッジ（外貨建てコスト）の有無で利益への感応度が異なる
> - **SaaS/テクノロジー**: 多くがUSD建て課金だが、現地法人の人件費は現地通貨建て。売上の為替感応度は通貨ペアに集中しやすく、コスト側は分散する傾向がある
> - **商社・卸売**: 仕入と販売の通貨が異なるケース（三国間取引）が多く、取引為替影響の構造が複雑。通貨ペアごとのネットポジション管理が重要
